Terms of use & notes

Please read this before you start using Hash Cracker.

1

Your data stays on your device

Hashing, wordlist matching and analysis all run inside your browser. The text, hashes and files you use are never uploaded, and there is no server or account. Only the web fonts are loaded from Google Fonts.

2

History is saved locally

Generate, Crack and Analyze history is kept in this browser's local storage (the latest 50 entries of each), including the text you hashed. Anyone who can use this browser profile can see it. You can delete single entries or clear everything from the History panel.

3

Acceptable use

This tool is for learning, research and testing systems or data that you own or have clear permission to test. Do not use it to access accounts, passwords or data that belong to someone else. You are responsible for following the laws that apply to you.

4

About the results

MD5 and SHA-1 are considered broken and should not protect passwords or sensitive data. Hash type detection is a guess based on format and length, so it can be wrong. Cracking only works by trying the words in your wordlist, and very large lists can be slow in a browser tab.

5

No warranty
